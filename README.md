# しわけくんEX

線対称・点対称の図形の性質を、ゲーム感覚で学ぶ小学校向けの算数Web教材です。

## 公開ページ

[しわけくんEXを開く](https://tt-sensei.github.io/sententaisyo/)

## 学べること

- 図形が線対称か点対称かを見分ける
- 対称の軸の本数を考える
- 図形の性質を、問題に答えながら確認する
- 制限時間内に問題へ取り組み、正答数やスコアを伸ばす

## 学習モード

- **線対称・点対称**：図形の対称性を見分けるモード
- **対称軸のかず**：図形に何本の対称の軸があるかを考えるモード

小学校高学年の算数「図形の性質」、特に線対称・点対称の学習に利用できます。
